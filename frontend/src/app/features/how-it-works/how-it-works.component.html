01

Como a análise funciona

Três etapas, um único envio.

  1. 1

    Envie o código

    Cole o arquivo ou selecione um repositório público do GitHub.

  2. 2

    Agentes analisam

    Código, testes e documentação são avaliados em paralelo.

  3. 3

    Receba o relatório

    Score, problemas priorizados e um resumo com próximos passos.

✓

O que é avaliado

  • ✓ Qualidade e legibilidade do código
  • ✓ Cobertura e clareza dos testes
  • ✓ Documentação e próximos passos
⌑

Privacidade

Análises anônimas não ficam vinculadas a uma conta. Entre para salvar o resultado e consultar o histórico quando o acesso à conta estiver disponível.
